**Restore what matters.** NovaRestore recovers lost inventories simply, safely, and without hassle — every death is captured as a snapshot, staff review it, and approved restorations flow back through Discord with a full audit trail.

## Review first. Restore with confidence.

NovaRestore records death snapshots so staff can inspect what a player lost, request a full or selective restoration, and review the request through Discord. Every action stays available in the audit history.

<Steps>
  <Step title="Capture">
    NovaRestore saves the death snapshot automatically the instant a player dies.
  </Step>
  <Step title="Inspect">
    Staff review the items in the in-game GUI.
  </Step>
  <Step title="Request">
    Staff select what to restore and submit the request.
  </Step>
  <Step title="Approve">
    Authorized staff review the request in Discord.
  </Step>
  <Step title="Track">
    Every decision stays in the audit record.
  </Step>
</Steps>

## Staff commands

| Command | Description |
|---|---|
| `/invrollback <player>` | Open death snapshots |
| `/invrollback history <player>` | Review restoration history |
| `/invrollback logs <player>` | Inspect audit events |
| `/invrollback export <yml\|json>` | Export audit records |

Also available as `/invrestore`. Permissions can be assigned by staff responsibility — see the [Permissions reference](/staff/permissions).

## Requirements & setup

<Warning>
  NovaRestore requires **Paper** specifically. It will not load on CraftBukkit, Spigot, or Fabric servers. Forks that extend Paper (such as Purpur) are generally compatible but are not officially tested.
</Warning>

| Requirement | Version |
|---|---|
| Server software | Paper |
| Minecraft version | 1.21.4 – 1.21.11 |
| Java version | Java 21 or newer |
| Languages | English and Spanish |
| Database | SQLite (default) or MySQL |

Discord approvals require a configured bot token, a request channel, and authorized role IDs. SQLite works out of the box for a straightforward setup — see [Configuration](/configuration/overview) for the full reference.
