**Restaura lo que importa.** NovaRestore recupera inventarios perdidos de forma simple, segura, y sin complicaciones — cada muerte se captura como una instantánea, el staff la revisa, y las restauraciones aprobadas se procesan a través de Discord con un rastro de auditoría completo.

## Revisa primero. Restaura con confianza.

NovaRestore registra instantáneas de muerte para que el staff pueda inspeccionar qué perdió un jugador, solicitar una restauración completa o selectiva, y revisar la solicitud a través de Discord. Cada acción permanece disponible en el historial de auditoría.

<Steps>
  <Step title="Captura">
    NovaRestore guarda la instantánea de muerte automáticamente en el instante en que un jugador muere.
  </Step>
  <Step title="Inspecciona">
    El staff revisa los ítems en la GUI dentro del juego.
  </Step>
  <Step title="Solicita">
    El staff selecciona qué restaurar y envía la solicitud.
  </Step>
  <Step title="Aprueba">
    El staff autorizado revisa la solicitud en Discord.
  </Step>
  <Step title="Rastrea">
    Cada decisión permanece en el registro de auditoría.
  </Step>
</Steps>

## Comandos de staff

| Comando | Descripción |
|---|---|
| `/invrollback <player>` | Abre instantáneas de muerte |
| `/invrollback history <player>` | Revisa el historial de restauraciones |
| `/invrollback logs <player>` | Inspecciona eventos de auditoría |
| `/invrollback export <yml\|json>` | Exporta registros de auditoría |

También disponible como `/invrestore`. Los permisos pueden asignarse según la responsabilidad del staff — consulta la [Referencia de permisos](/es/staff/permissions).

## Requisitos y configuración

<Warning>
  NovaRestore requiere **Paper** específicamente. No cargará en servidores CraftBukkit, Spigot, o Fabric. Los forks que extienden Paper (como Purpur) son generalmente compatibles pero no están probados oficialmente.
</Warning>

| Requisito | Versión |
|---|---|
| Software del servidor | Paper |
| Versión de Minecraft | 1.21.4 – 1.21.11 |
| Versión de Java | Java 21 o más reciente |
| Idiomas | Inglés y español |
| Base de datos | SQLite (predeterminado) o MySQL |

Las aprobaciones de Discord requieren un token de bot configurado, un canal de solicitudes, e IDs de rol autorizados. SQLite funciona de fábrica para una configuración sencilla — consulta [Configuración](/es/configuration/overview) para la referencia completa.
