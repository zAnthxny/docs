Instalar NovaRestore toma menos de dos minutos. El plugin se distribuye como un jar autocontenido sin dependencias externas — colócalo en tu carpeta `plugins/`, inicia el servidor, y genera todo lo que necesita automáticamente. Esta página te guía a través de cada paso y te muestra cómo se ve un primer arranque limpio.

## Requisitos

Antes de instalar, confirma que tu entorno cumple estos requisitos.

| Requisito | Versión mínima |
|---|---|
| Software del servidor | Paper |
| Versión de Minecraft | 1.21.4 |
| Versión máxima probada | 1.21.11 |
| Java | Java 21 |

<Warning>
  NovaRestore **no** cargará en Spigot, CraftBukkit, o Fabric. Requiere la API de Paper para varias funciones principales. Si tu servidor ejecuta una de esas plataformas, debes migrar a Paper antes de continuar.
</Warning>

## Pasos de instalación

<Steps>
  <Step title="Confirma que tu servidor cumple los requisitos">
    Verifica la versión de tu servidor ejecutando el comando `version` en la consola del servidor. La salida debe mostrar `Paper` en la cadena de versión y una versión de Minecraft entre 1.21.4 y 1.21.11. Confirma tu versión de Java con `java -version` en la terminal de tu sistema — la salida debe mostrar la versión 21 o superior.

    ```text console
    > version
    This server is running Paper version 1.21.4-... (MC: 1.21.4)
    ```

    ```text terminal
    $ java -version
    openjdk version "21.0.3" ...
    ```
  </Step>

  <Step title="Descarga y coloca el jar">
    Descarga el `NovaRestore-x.x.x.jar` más reciente desde la página oficial de lanzamientos y colócalo en el directorio `plugins/` de tu servidor. No renombres el jar — el plugin usa su propio nombre de archivo para el registro y las verificaciones de actualización.

    Tu carpeta `plugins/` debería verse así después de colocar el archivo:

    ```text plugins/
    plugins/
    ├── NovaRestore-1.0.0.jar
    └── ... (other plugins)
    ```
  </Step>

  <Step title="Inicia el servidor">
    Inicia (o reinicia) tu servidor normalmente. En el primer arranque, NovaRestore crea su directorio de configuración y todos los archivos requeridos automáticamente — no necesitas crear ninguna carpeta o archivo manualmente.

    Después de que la secuencia de arranque se complete, tu directorio `plugins/` contendrá:

    ```text plugins/
    plugins/
    ├── NovaRestore-1.0.0.jar
    └── NovaRestore/
        ├── config.yml
        ├── data.db          ← default SQLite database
        └── messages.yml
    ```

    <Note>
      Si pretendes usar MySQL en lugar de la base de datos SQLite predeterminada, no pobles la base de datos con datos en vivo antes de cambiar. Define tus credenciales de MySQL en `config.yml` antes de que el servidor procese cualquier muerte de jugador.
    </Note>
  </Step>

  <Step title="Verifica el arranque en la consola">
    Desplázate por la salida de tu consola después del arranque. NovaRestore imprime un banner ASCII con estilo cuando carga exitosamente. Busca un bloque que se parezca al siguiente:

    ```text console
    [NovaRestore] ==============================================================
    [NovaRestore]   ___              ____       _ _ _                _
    [NovaRestore]  |_ _|_ ____   __ |  _ \ ___ | | | |__   __ _  ___| | __
    [NovaRestore]   | || '_ \ \ / / | |_) / _ \| | | '_ \ / _` |/ __| |/ /
    [NovaRestore]   | || | | \ V /  |  _ < (_) | | | |_) | (_| | (__|   <
    [NovaRestore]  |___|_| |_|\_/   |_| \_\___/|_|_|_.__/ \__,_|\___|_|\_\
    [NovaRestore]
    [NovaRestore]               !Plugin NovaRestore activado!
    [NovaRestore]             Version: 1.0.0
    [NovaRestore] ==============================================================
    ```

    Si el banner no aparece, revisa la consola en busca de mensajes de error. Las causas comunes incluyen una versión incompatible de Paper o una versión de Java por debajo de 21.

    <Note>
      En el primer arranque, NovaRestore registra dos comandos: `/invrollback` (el comando principal de staff) e `/invrestore` (un alias). Ambos están disponibles inmediatamente después de que el plugin carga — no se requiere reinicio del servidor después de cambios de configuración en la configuración de comandos.
    </Note>
  </Step>

  <Step title="(Opcional) Migra datos heredados de InvRollback">
    Si tu servidor previamente ejecutó un plugin **InvRollback** más antiguo, NovaRestore detecta automáticamente la carpeta de datos heredada al arrancar y migra todas las instantáneas existentes a su propia base de datos.

    Busca la siguiente línea en la consola para confirmar que la migración se ejecutó:

    ```text console
    [NovaRestore] Legacy InvRollback data detected. Migrating snapshots... done. (N records imported)
    ```

    Una vez que la migración se completa, la carpeta original `InvRollback/` se deja intacta para que puedas verificar los datos antes de eliminarla manualmente.

    <Info>
      La migración automática solo se ejecuta una vez. Si reinicias el servidor después de la migración, NovaRestore no intentará reimportar los datos heredados aunque la carpeta antigua siga presente.
    </Info>
  </Step>
</Steps>
